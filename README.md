#  Fernanda Chaves Canaud

Site institucional desenvolvido para divulgar o trabalho da pianista e professora Fernanda Chaves Canaud, apresentando sua trajetória, especialidades, depoimentos de alunos e canais de contato.

##  Sobre o Projeto

A aplicação foi construída com foco em:

- Apresentação profissional da pianista
- Divulgação de aulas particulares de piano
- Exibição de depoimentos de alunos
- Experiência moderna e responsiva
- Navegação simples e intuitiva

##  Funcionalidades

-  Página inicial institucional
-  Apresentação da professora
-  Seção de depoimentos
-  Envio de novos depoimentos
-  Layout responsivo
-  Música de fundo
-  Integração com WhatsApp para contato

##  Como Executar o Projeto

### 1. Clone o repositório

```bash
git clone URL_DO_REPOSITORIO
```

### 2. Acesse a pasta

```bash
cd projeto-fernanda-canaud
```

### 3. Instale as dependências

```bash
npm install
```

### 4. Execute o projeto

```bash
npm run dev
```

### 5. Abra no navegador

```bash
http://localhost:3000
```

##  Responsividade

O projeto foi desenvolvido seguindo a abordagem Mobile First, garantindo boa experiência em:

- Smartphones
- Tablets
- Notebooks
- Monitores Desktop

##  Objetivo

Criar uma presença digital elegante e profissional para divulgação de aulas de piano, permitindo que novos alunos conheçam o trabalho da professora e entrem em contato de forma rápida.
